Мінімалістичний офлайн-тренажер англійської лексики для української аудиторії. Увесь застосунок — один HTML-файл: без бекенду, без збірки, без залежностей. Працює прямо в браузері й ставиться на телефон як PWA.

## Оновлення

Нова версія ставиться лише з дозволу. Гра тихо перевіряє `version.json` поруч із собою; якщо там новіша
версія — на спокійному екрані показує «Нова версія … · Що змінилось · 🔄 Оновити / Пізніше»
(посеред тренування — лише смужка вгорі). Прогрес, слова й профілі зберігаються.

Як випустити нову версію:
1. В `index.html` змінити `const APP_VERSION="РРРР.ММ.ДД ГГ:ХХ"`.
2. У `version.json` вписати ту саму версію й коротко, що змінилось:
   `{ "version": "2026.10.12 10:00", "changes": ["…", "…"] }`
3. Залити обидва файли. `sw.js` між версіями **не міняти** — саме тому гра й не оновлюється сама.
